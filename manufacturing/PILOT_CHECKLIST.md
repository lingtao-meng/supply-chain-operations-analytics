# 标准工时与试产复核表

## 作业测量

| 记录项 | 记录口径 |
| --- | --- |
| 工序与条件 | 工序编号、作业方法及版本、测时起止点、工位、工具、班次、产品与人员熟练度 |
| 时间观测 | 逐循环记录作业时间及人机重叠，分开记录换型、故障、等料和阻塞，注明异常的原因和处理口径 |
| 样本复核 | 按人、班次和工位看均值、离散程度和异常记录，覆盖计划适用的条件。根据初测方差与精度要求确定补测量 |
| 工时定额 | 正常时间＝有效观测均值 × 评比系数。若宽放率按标准时间比例定义，标准时间＝正常时间 ÷（1－宽放率） |
| 录入与审批 | 保留原始记录、版本及审批。如果班次净工时已扣除某项休息或计划停机，避免再用同一项宽放扣减产能 |

本项目的工序编号和名义工时取自公开基准。具体工步、异常判定、质量检查和安全要求需在工序作业指导书上确认后再测。

## 试产前后对照

| 环节 | 数据与动作 | 复核指标 |
| --- | --- | --- |
| 试产前 | 锁定基线和改善方案的工序分配、标准工时、人员、缓冲与净生产时间 | 人数、总缓冲位、需求节拍、工位峰值负荷 |
| 试产中 | 分班记录计划与实际产量、合格数、工位忙闲、阻塞、等料、停机、换型与在制峰值 | 合格件数/净生产小时、准时达成、各类损失占比、在制峰值 |
| 比较收益 | 对齐品种、班次净时长和人员口径，保留不达标班次；按班统计变异和短缺量 | 每百合格件人时、达标率、低产出班次分位数、增量缓冲占用 |
| 固化方案 | 复核安全和质量后更新工序分配、工位作业顺序、在制上限、点检要求和异常响应 | 工艺与质量签核、培训记录、复查时间及责任人 |

若试产出现工位名义负荷低但阻塞高，先区分缓冲空间不足、下游设备异常和整班工时变慢。明确原因后再决定重新分配工序、调整缓冲或处理作业异常，并用同一统计口径复验。
